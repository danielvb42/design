# Band

Faixa azul de chamada, de largura total, perto do fim da página.

- `<div class="eq-band">` com título (`eq-band-title`, 32px/400) e UM botão branco de texto azul (`eq-btn eq-band-btn`).
- Fundo `primary`, texto `on-primary`, cantos retos, 48px de padding.
- É o único lugar em que o azul vira fundo; uma por página.
- Você fornece o título e o rótulo do botão.
