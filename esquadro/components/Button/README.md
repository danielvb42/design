# Button

Botões de ação; um primário por tela.

- **Primário** (`eq-btn eq-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`eq-btn-secondary`): `inverse-bg` (carvão) com texto `inverse-ink`.
- **Texto** (`eq-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-none` (0), padding 12px 16px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="eq-caret">`.
