# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="eq-tabs" role="tablist">` com `<button class="eq-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Sublinhado de 2px em `primary` e peso 600 na aba ativa; inativas em `ink-muted`.
- Você fornece de 2 a 5 rótulos curtos.
