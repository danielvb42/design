# KPI

Número de destaque com rótulo e variação.

- `eq-kpi-value` usa o estilo `display-md` em `ink`, peso 300; a variante `.sm` usa `headline`.
- `eq-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `eq-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
