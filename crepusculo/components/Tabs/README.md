# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="cr-tabs" role="tablist">` com `<button class="cr-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas em pílula com borda `line`; a ativa fica cheia em `primary` com texto `on-primary`.
- Você fornece de 2 a 5 rótulos curtos.
