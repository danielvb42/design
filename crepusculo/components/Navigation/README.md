# Navigation

Navegação lateral de 240px com ícone-linha e rótulo.

- Lista de `<a>` dentro de `<nav class="cr-nav">`; o item atual leva `aria-current="page"`.
- Item atual: fundo `nav-line` sobre o índigo, texto `nav-ink`; demais em `nav-ink-muted`.
- Ícones-linha de 20px, traço 1,5px, sem preenchimento.
- Você fornece os itens (rótulo, destino e ícone); no máximo 7.
