# Band

Faixa verde-petróleo que fecha toda página.

- `<div class="cr-band">` com um título (`cr-band-title`, 28px/540) e UM botão branco (`cr-btn cr-band-btn`).
- Fundo `teal-deep`, texto `on-primary`, 64px de padding, `radius-lg`.
- É sempre o último bloco; nunca duas na mesma página, nunca no meio do conteúdo.
- Sobre o índigo (navegação, bloco escuro), o botão é a pílula violeta: `cr-btn cr-btn-onDark`.
- Você fornece o título de fechamento e o rótulo do botão.
