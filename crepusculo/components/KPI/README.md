# KPI

Número de destaque com rótulo e variação.

- `cr-kpi-value` usa o estilo `display-xl` em `ink`, entrelinha 0,96; a variante `.sm` usa `display-lg`.
- `cr-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `cr-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
