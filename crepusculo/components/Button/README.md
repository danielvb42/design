# Button

Botões de ação; um primário por tela.

- **Primário** (`cr-btn cr-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`cr-btn-secondary`): contorno `line-strong` sobre `surface`, texto `ink`.
- **Texto** (`cr-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-md` (8px), padding 12px 20px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="cr-caret">`.
