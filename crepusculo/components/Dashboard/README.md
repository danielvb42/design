# Dashboard

Página de exemplo que combina navegação, cabeçalho, abas, KPIs, gráficos e tabela.

- Estrutura: `cr-app` › `cr-side` + `cr-main`; grades `cr-grid4` (KPIs) e `cr-grid2` (7/5).
- Os dados são fictícios e servem só para mostrar o estilo.
- Use como ponto de partida para novos painéis: troque títulos, números e tabelas.
