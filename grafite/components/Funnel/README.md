# Funnel

Contagem por etapa: KPI total, barra empilhada proporcional e tabela com quantidade, valor e tempo médio.

- Barra de 8px, segmentos separados por 2px, cores `data-1…5` na ordem das etapas.
- Tabela sem linhas de grade; números alinhados à direita com `tabular-nums`; tempo médio em `ink-muted`.
