# Navigation

Barra lateral com ícones-linha e rótulos; o item ativo ganha fundo grafite suave.

- Itens de 48px, `radius-sm`, texto 17px em `ink-muted`; ícone 24px traço 1,5.
- Ativo (`aria-current="page"`): fundo `primary-soft`, texto `ink` peso 600.
- Hover: fundo `bg`, texto `ink`. Agrupe itens com espaço (`space-6`), não com divisórias.
