# Chip

Botões de alternância para trocar a métrica de um gráfico ou ligar/desligar séries de uma legenda.

- `gf-chip`: borda `line-strong`, `radius-sm`, 32px de altura.
- Selecionado (`aria-pressed="true"`): fundo `primary-soft`, peso 600.
- Chip de legenda leva `gf-swatch` de 14px com a cor da série.
