# KPI

Número grande e leve com rótulo curto ao lado — a assinatura tipográfica do sistema.

- Em linha (`gf-kpi`): valor `kpi-xl` (44px, peso 300) + rótulo `label` em `ink-muted` na linha de base.
- Empilhado (`gf-kpi-stack`): valor `kpi` em cima, rótulo em até duas linhas embaixo — para grades de "Outros dados".
- O consumidor formata o número (milhar com ponto, % com vírgula).
