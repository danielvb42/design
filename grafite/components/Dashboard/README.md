# Dashboard

Exemplo de tela completa — sidebar, título com ação primária, painel único com abas e blocos separados por linhas. Alterne o tema da página para ver a versão escura.

- Composição: `Navigation` + `Button` primário + `Tabs` + `Funnel` + `Donut` + `LineChart`.
- Tudo dentro de UM `gf-panel`; blocos divididos por `line` de 1px, nunca cards soltos.
