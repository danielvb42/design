# Button

Botões retangulares de cantos discretos; o primário é grafite cheio, uma vez por tela.

- **Primário** (`gf-btn gf-btn-primary`): `primary` + `on-primary`; pode levar seta de menu (`gf-caret`) como "Criar ▾". No Escuro fica grafite-claro com texto escuro.
- **Secundário** (`gf-btn-secondary`): `surface` com borda `line-strong`, texto `ink`.
- **Texto** (`gf-btn-text`): `accent`, para ações terciárias ("Ver detalhes").
- Altura 44px, `radius-sm`, rótulo 16px peso 600. Foco: anel `focus` 2px.
