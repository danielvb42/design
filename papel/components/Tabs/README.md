# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="pp-tabs" role="tablist">` com `<button class="pp-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Sublinhado de 2px em `ink` na aba ativa; o laranja não marca seleção.
- Você fornece de 2 a 5 rótulos curtos.
