# Button

Botões de ação; um primário por tela.

- **Primário** (`pp-btn pp-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`pp-btn-secondary`): `surface` (branco) com borda `line-strong` e texto `ink`.
- **Texto** (`pp-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-md` (8px), padding 10px 18px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="pp-caret">`.
