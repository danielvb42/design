# Badge

Etiqueta curta de variação ou status, sempre ao lado do número que qualifica.

- **Alta** (`vn-badge vn-badge-up`): `success-soft` + `success-ink`, com sinal "+".
- **Queda** (`vn-badge-down`): `danger-soft` + `danger-ink`, com sinal "−".
- **Neutra** (`vn-badge-neutral`): `navy-50` + `link`, para rótulos como "Novo".
- **Status** (`vn-status`): bolinha `success` + texto `success-ink`, ao lado de um título ("No ritmo").
- Nunca dependa só da cor: o sinal ou a palavra carregam o significado.
