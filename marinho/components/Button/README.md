# Button

Botões em pílula: o primário (azul-marinho com brilho) aparece no máximo uma vez por tela; o resto é fantasma ou link.

- **Primário** (`vn-btn vn-btn-primary`): fundo `primary`, texto `on-primary`, sombra `shadow-glow`; hover em `primary-hover`.
- **Fantasma** (`vn-btn-ghost`): texto `ink-muted`, sem fundo — para "Pular", "Cancelar".
- **Link** (`vn-btn-link`): texto `link` com seta → — para "Ver tudo".
- Rótulo com verbo, sentence case. Altura 52px, padding horizontal `space-6`.
- Foco: anel de 2px em `focus`, afastado 3px.
