# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="pr-tabs" role="tablist">` com `<button class="pr-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Sublinhado de 2px em `primary` (branco) na aba ativa; inativas em `ink-muted`.
- Você fornece de 2 a 5 rótulos curtos.
