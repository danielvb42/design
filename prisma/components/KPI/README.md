# KPI

Número de destaque com rótulo e variação.

- `pr-kpi-value` usa o estilo `display-md` em `ink`; a variante `.sm` usa `headline`.
- `pr-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `pr-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
