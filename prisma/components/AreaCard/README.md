# AreaCard

Card inteiro na cor de identidade de uma área do painel.

- `<div class="pr-area" style="--area:var(--data-N)">` com etiqueta (`pr-area-pill`), número e rótulo.
- Sobre violeta e azul o texto é `ink` (branco); sobre amarelo, ciano, verde e coral passe `--area-ink:var(--on-primary)` (preto), que é o par que passa 4,5:1.
- Uma identidade por área; não coloque duas cores de identidade no mesmo bloco, nem use a cor de uma área em outra.
- Você fornece o nome da área, o número e o rótulo.
