# Button

Botões de ação; um primário por tela.

- **Primário** (`cz-btn cz-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`cz-btn-secondary`): pílula carvão: `surface` com texto `ink`, sem borda.
- **Texto** (`cz-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-pill`, padding 10px 15px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="cz-caret">`.
