# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="cz-tabs" role="tablist">` com `<button class="cz-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas-pílula; a selecionada sobe para `surface-raised` com texto `ink` — seleção é degrau, não cor.
- Você fornece de 2 a 5 rótulos curtos.
