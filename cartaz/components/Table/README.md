# Table

Tabela de dados com cabeçalho discreto.

- `<table class="cz-table">`; colunas numéricas levam `class="num"` (alinhadas à direita, algarismos tabulares).
- Cabeçalho em `ink-muted`; linhas separadas por `line` de 1px, sem zebra.
- Situação entra como Badge, com texto.
- Você fornece colunas e linhas; até 8 colunas.
