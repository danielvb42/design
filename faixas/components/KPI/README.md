# KPI

Número de destaque com rótulo e variação.

- `fx-kpi-value` usa o estilo `display-lg` em `ink`, peso 300; a variante `.sm` usa `heading-xl`.
- `fx-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `fx-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
