# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="fx-tabs" role="tablist">` com `<button class="fx-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas-pílula; a ativa fica cheia em `primary` com texto `on-primary`, como o chip de filtro ativo.
- Você fornece de 2 a 5 rótulos curtos.
