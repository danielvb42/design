# Band

Faixa azul de largura total: o momento de ação da página.

- `<div class="fx-band">` com título (`fx-band-title`, 35px/300) e UM botão de contorno branco (`fx-btn fx-band-btn`).
- Fundo `primary`, texto `on-primary`, sem raio, 48px de padding; igual nos dois temas.
- No máximo uma por página. Para a ação quente use `fx-btn fx-btn-warm`; para o botão de chamada de 48px, `fx-btn-lg`.
- Você fornece o título e o rótulo do botão.
