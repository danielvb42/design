# Button

Botões de ação; um primário por tela.

- **Primário** (`fx-btn fx-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`fx-btn-secondary`): pílula transparente com contorno `line-strong` e texto `ink`.
- **Texto** (`fx-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-pill`, padding 10px 24px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="fx-caret">`.
