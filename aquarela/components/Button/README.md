# Button

Botões de ação; um primário por tela.

- **Primário** (`aq-btn aq-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`aq-btn-secondary`): pílula transparente com contorno `line-strong` e texto `ink`.
- **Texto** (`aq-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-pill`, padding 10px 20px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="aq-caret">`.
