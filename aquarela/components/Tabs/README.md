# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="aq-tabs" role="tablist">` com `<button class="aq-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas em pílula com contorno `line-strong`; a ativa fica cheia em `primary` (tinta) com texto `on-primary`.
- Você fornece de 2 a 5 rótulos curtos.
