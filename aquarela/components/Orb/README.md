# Orb

Card de destaque com uma mancha radial de cor pastel por trás do texto.

- `<div class="aq-orb" style="--orb:var(--orb-mint)">` com título em serifa (`aq-orb-title`) e uma linha de apoio (`aq-orb-text`).
- Cinco manchas: `orb-mint`, `orb-peach`, `orb-lavender`, `orb-sky`, `orb-rose`. A cor é só atmosfera: não codifica status.
- Fundo `bg-soft`, `radius-xxl` (24px); o texto fica em `ink`, sempre legível sobre os pastéis.
- Até três por linha; não use a mancha em botões nem em texto.
- Você fornece o título curto e a linha de apoio.
