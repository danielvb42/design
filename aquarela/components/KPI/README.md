# KPI

Número de destaque com rótulo e variação.

- `aq-kpi-value` usa o estilo `display-xl` em `ink`, serifa de peso 300; a variante `.sm` usa `display-md`.
- `aq-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `aq-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
