# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="qd-tabs" role="tablist">` com `<button class="qd-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas-pílula com borda `line`; a ativa fica cheia em `primary` (preto) com texto `on-primary`.
- Você fornece de 2 a 5 rótulos curtos.
