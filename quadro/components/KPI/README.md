# KPI

Número de destaque com rótulo e variação.

- `qd-kpi-value` usa o estilo `stat-display` em `ink`; a variante `.sm` usa `heading-2`.
- `qd-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `qd-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
