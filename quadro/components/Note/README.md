# Note

Card em tom pastel, como uma nota colada no quadro.

- `<div class="qd-note" style="--note:var(--yellow)">` com título (`qd-note-title`, 22px/500) e texto (`qd-note-text`).
- Tons: `yellow`, `coral-light`, `teal-light`, `rose-light`, `orange-light`; texto sempre em `ink`; `radius-xxxl` (28px).
- Misture notas com cards brancos na mesma tela; a cor agrupa assuntos, não codifica status sozinha — o título diz o que é.
- Você fornece o título e uma frase curta.
