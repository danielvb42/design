# Button

Botões de ação; um primário por tela.

- **Primário** (`qd-btn qd-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`qd-btn-secondary`): pílula transparente com contorno `line-strong` e texto `ink`.
- **Texto** (`qd-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-pill`, padding 12px 24px, altura mínima 44px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="qd-caret">`.
