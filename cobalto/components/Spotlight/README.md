# Spotlight

Card de destaque com um brilho azul radial por trás do conteúdo.

- `<div class="cb-spot">` com título (`cb-spot-title`), frase de apoio e um botão secundário.
- O brilho nasce de baixo, em `primary-glow` → `primary` → transparente, sobre `surface`.
- Um por tela; o texto fica na metade de cima, onde o fundo ainda é escuro.
- Você fornece o título, a frase e o rótulo do botão.
