# KPI

Número de destaque com rótulo e variação.

- `cb-kpi-value` usa o estilo `display-lg` em `ink`; a variante `.sm` usa `display-md`.
- `cb-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `cb-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
