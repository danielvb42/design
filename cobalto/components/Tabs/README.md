# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="cb-tabs" role="tablist">` com `<button class="cb-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Sublinhado de 2px em `ink` (branco) na aba ativa — o azul não tem contraste para marcar seleção.
- Você fornece de 2 a 5 rótulos curtos.
