# Button

Botões de ação; um primário por tela.

- **Primário** (`tc-btn tc-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`tc-btn-secondary`): `surface-raised` com borda `line` e texto `ink`.
- **Texto** (`tc-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-md` (8px), padding 8px 16px, altura mínima 36px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="tc-caret">`.
