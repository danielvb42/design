# KPI

Número de destaque com rótulo e variação.

- `tc-kpi-value` usa o estilo `display-lg` em `ink`; a variante `.sm` usa `heading-xl`.
- `tc-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `tc-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
