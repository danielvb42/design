# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="tc-tabs" role="tablist">` com `<button class="tc-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Abas-pílula; a ativa sobe um degrau (fundo `primary-soft`, texto `ink`), as demais ficam transparentes em `ink-muted`.
- Você fornece de 2 a 5 rótulos curtos.
