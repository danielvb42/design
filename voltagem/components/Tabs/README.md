# Tabs

Abas para trocar a visão do painel (Acervo, Produtividade, Metas).

- `<div class="vt-tabs" role="tablist">` com `<button class="vt-tab" role="tab">`; a ativa leva `aria-selected="true"`.
- Aba ativa ganha fundo `surface` e texto `ink`, com `radius-md`; inativas transparentes em `ink-muted`.
- Você fornece de 2 a 5 rótulos curtos.
