# Band

Faixa amarela de chamada: o único lugar em que o amarelo ocupa uma área grande.

- `<div class="vt-band">` com título (`vt-band-title`), texto opcional e UM botão preto (`vt-btn vt-band-btn`).
- Fundo `primary`, texto `on-primary` (preto sobre amarelo).
- No máximo uma por página; não alterne duas faixas seguidas.
- Você fornece o título, a frase de apoio e o rótulo do botão.
