# Button

Botões de ação; um primário por tela.

- **Primário** (`vt-btn vt-btn-primary`): `primary` com texto `on-primary`.
- **Secundário** (`vt-btn-secondary`): `surface-raised` com borda `line-strong` e texto `ink`.
- **Texto** (`vt-btn-text`): cor `accent`, para ações terciárias como "Ver detalhes".
- Raio `radius-md` (8px), padding 10px 18px, altura mínima 40px. Foco: anel `focus` de 2px.
- Você fornece o rótulo (verbo curto) e, se precisar de menu, um `<span class="vt-caret">`.
