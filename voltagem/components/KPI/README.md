# KPI

Número de destaque com rótulo e variação.

- `vt-kpi-value` usa o estilo `stat-display`, sempre em `primary` (amarelo); a variante `.sm` usa `display-sm`.
- `vt-kpi-label` em `ink-muted`, sempre minúsculo: "em tramitação".
- `vt-delta up|down` leva seta ▲/▼ e texto — a cor nunca é o único sinal.
- Você fornece valor (formato brasileiro), rótulo e variação.
