# Card

O contêiner de tudo: superfície branca de cantos grandes flutuando sobre o fundo lavanda.

- `vn-card`: `surface`, `radius-xl` (32px), `shadow-card`, padding `space-6`.
- Título `heading-2` à esquerda; controles (filtro "Mensal ▾", status) na mesma linha, à direita.
- Mini-cards de KPI dentro de um card usam `surface-raised` + `shadow-float` + `radius-md`.
- Gráfico de área: linha 3px `primary`, preenchimento `violet-50` desvanecendo para transparente.
