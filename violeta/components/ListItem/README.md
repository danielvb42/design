# ListItem

Linha de transação ou registro: bolha de ícone (ou avatar), título com data abaixo, valor à direita.

- Bolha de 48px em `-soft` da categoria com ícone-linha na cor da categoria (`vn-bubble-info`, `-success`, `-warning`, `-brand`).
- Título `body` em `ink`; data `body-sm` em `ink-muted` ("Hoje, 16:36").
- Valor estilo `amount`: neutro em `ink`; entradas em `success-ink` com "+", saídas destacadas em `danger-ink` com "−".
- Gap vertical entre itens `space-5`. Até 3–5 itens por card, com "Ver tudo →" no rodapé.
